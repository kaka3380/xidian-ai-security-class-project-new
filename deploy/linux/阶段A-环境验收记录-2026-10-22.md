## 安装中解决的问题

1. WSL 内置 Ubuntu 下载返回 `0x80072f78`。改为从 Microsoft 官方发行版清单取得 Ubuntu 官方安装包，验证 SHA-256 后使用 `--from-file` 安装到 E 盘。
2. WSL NAT 模式提示 Windows localhost 代理不可用，部分直连下载反复中断。通过 Windows 下载离线 wheel，所有包继续接受原锁文件哈希校验。
3. 锁文件中的索引选项覆盖了 pip 的额外 PyTorch 源，导致找不到 CUDA wheel。移除该索引指令，保持版本和包哈希；从缓存恢复已下载包。PyTorch 的下载 CDN 中断时，使用官方主域名的同一文件并校验相同哈希。
