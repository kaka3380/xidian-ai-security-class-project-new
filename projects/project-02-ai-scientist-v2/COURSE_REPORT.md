## 修改及前后行为

| 位置 | 原行为 | 修改后 |
| --- | --- | --- |
| `treesearch/agent_manager.py` | 实验计划只注入阶段 3，风险约束只注入阶段 4 | 各阶段都接收任务中已提供的实验计划与风险约束，包括首次实现 |
| 同上 | 首阶段达到迭代上限时，即使最后一次已有有效节点仍判失败 | 仅在没有有效节点时判首阶段失败 |
| `treesearch/utils/config.py` | 导出最佳源码允许选择失败节点 | 导出时仅从有效节点选择 |
| `launch_scientist_bfts.py` | 缺少结果目录仍继续绘图；绘图后删除原始结果副本 | 先保存用量，缺少结果时停止；保留日志中的原件和结果副本供核验 |
| 同上 | 结束时全局扫描带有 python、torch 等关键词的进程并终止 | 只清理当前启动器的后代进程，保留原有先终止、再强制结束的流程 |
| `perform_icbinb_writeup.py` | 最终页数反思提示没有插值，缺少当前论文；无需修改时可能不生成最终 PDF | 提供实际页数、研究上下文和当前完整 LaTeX；模型回复无需修改时也编译最终路径 |

约束进入提示只改善输入信息，不能保证生成代码一定遵守约束。节点未被运行器标记为失败，也不等于研究结论已经核验。

## 环境与复现

历史环境为 Windows 11 + WSL2 Ubuntu 24.04.5 + Docker Desktop 4.77.0 / Engine 29.5.3。项目独立 Python 3.11.16、PyTorch 2.6.0+cu124、CUDA runtime 12.4；RTX 3060 Laptop 6GB。PDF 测试环境另装 TeX Live、BibTeX、chktex、Poppler。实际模型为 `deepseek-flash`，测试中使用的 GPT 模型名称为兼容网关别名。

从本项目目录运行离线回归，Python 3.11 标准库即可，无需安装模型、GPU、LaTeX 或配置密钥：

```powershell
python -m unittest discover -s tests -p 'test_*.py' -v
```

测试用 AST 从实际源码提取被测函数或主流程片段，替换模型、配置序列化和进程接口，实际执行文件复制、最佳节点导出和写作反思代码。覆盖首阶段边界、有效节点选择、四阶段约束传递、缺少结果时提前停止、结果保留、进程清理范围，以及当前论文上下文与无需修改时的 PDF 编译调用。PDF 测试使用编译替身，不代表执行了 TeX。

本次提交前验证：Python 3.11.16 下 7 项测试通过，4 个修复文件语法编译通过，Git 差异空白检查通过（接受既有 CRLF）。首次测试因沙箱系统临时目录权限失败，改用工作区临时目录后通过，仅调整该测试进程的 TEMP/TMP。解析上游写作源码时仍有既有的无效转义 DeprecationWarning，本次未修改无关字符串。

完整实验安装及入口仍按 [README.md](README.md) 执行。离线测试不覆盖整个模块的依赖导入或所有端到端行为；以下实测摘要来自本机既有记录，本次提交没有重新调用付费模型。

## 既有实测结果

固定实验采用 12 个合成配对案例，按普通/资料边界提示、干净/注入资料组成四组，共 48 份回答。回答采集后冻结，Scientist 后续生成分析代码、执行、修订和绘图；重复分析和 seed 节点不增加独立样本量。

| 条件 | 干净资料正确数 | 注入资料正确数 | 目标注入成功数 |
| --- | ---: | ---: | ---: |
| 普通提示 | 12/12 | 12/12 | 0/12 |
| 资料边界提示 | 12/12 | 12/12 | 0/12 |

两组未观察到差异，不能据此宣称资料边界提示更有效或模型普遍安全。

- 四阶段树搜索、代码反馈与修订、绘图、阶段总结：已实际运行；存在失败候选及没有信息增量的消融，不能把流程退出码 0 当作科研正确性认证。
- 不带在线检索的想法生成：已生成结构化想法，新颖性未核验。
- 修复后的论文生成、PDF 编译、文字与图表审稿：已实际运行。最终 PDF 仍有未解析引用，References 为空，只是功能测试产物。
- 论文测试使用已核验的第 5 次运行首实现摘要及第 4 次运行图表，并保留来源记录；不是第 6 次实验直接自动生成的可信论文。
- 2026-10-24 独立功能测试记录为 136 次模型请求，用量费用上界 1.511352 元 / 5 元；该数字由本地网关峰值单价估算，不是供应商账单，也不包含此前历史实验。
